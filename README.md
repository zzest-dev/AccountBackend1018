# AccountBackend1018

Аккаунтный сервер MadOut2 BigCityOnline **10.18 / 100118** на C# и .NET 8. Хранит аккаунты в SQLite, обрабатывает покупки и прогресс одиночной игры. Клиент подключается к нему через штатный бинарный TCP-протокол игры.

Для работы нужен оригинальный Android APK 10.18 ARMv7, обработанный [APKPatcher1018](https://github.com/zzest-dev/APKPatcher1018). Патчер подключён к этому проекту как Git-сабмодуль `patcher`.

## Что работает

- Гостевая регистрация, вход, сессии и загрузка аккаунта.
- Новый аккаунт: ник `user <id>`, **10 000 000 монет** и **10 000 кристаллов**.
- Гараж, одежда, оружие и боезапас, детали и услуги тюнинга.
- Винилы, подвеска, номера, нитро, ремонт, доставка и смена ника.
- Сохранение профиля, покупок и прогресса миссий.
- Первая миссия `Get Drugs`: **250 кристаллов** за успешное прохождение.
- Проверки баланса, владения предметами и оплаты изменений. Повтор принятого запроса не списывает деньги и не выдаёт награду заново.

Этот сервер предназначен для аккаунтов и одиночной игры. В коде есть интерфейсы для будущего игрового сервера и моста Mirror ↔ UNet, их реализации пока нет. Вход через Facebook и другие внешние провайдеры не реализован.

## Быстрый запуск сервера

Нужен .NET 8 SDK для сборки из исходников:

```sh
dotnet run --project src/AccountBackend -c Release
```

В готовой самостоятельной Windows-сборке достаточно запустить `AccountBackend.exe`; устанавливать .NET, Python или Unity для неё не требуется. Настройки `server.json` и папка `data` должны находиться рядом с программой. Остановка: Ctrl+C. Одновременно два сервера на одном IP и порту работать не могут.

```json
{
  "listen_host": "0.0.0.0",
  "listen_port": 10118,
  "database": "data/accounts.sqlite3",
  "catalog_directory": "data",
  "new_account": { "coins": 10000000, "diamonds": 10000 }
}
```

`0.0.0.0` означает прослушивание интерфейсов ПК. В клиенте указывается доступный **IPv4 самого ПК**, например `192.168.1.10`, а не `0.0.0.0`. Это TCP, не HTTP: открыть сервер в браузере не получится. Для телефона в домашней сети разрешите входящий TCP-порт 10118 от своей локальной сети. Сервер не изменяет брандмауэр автоматически.

Другой конфиг и переопределение адреса:

```sh
dotnet AccountBackend.dll --config server.local.json --host 127.0.0.1 --port 10118
```

Пути внутри конфига считаются относительно самого файла конфига. Начальный баланс применяется при регистрации и не меняет уже созданные аккаунты.

## Подготовить APK и подключить телефон

Патчер использует Python 3.11+, JDK и Android SDK Build Tools. Unity для готового патчера не нужен. Оригинальные APK/OBB в репозитории не распространяются.

```sh
python patcher/patch.py original-10.18.apk --host 192.168.1.10 --port 10118 --android-sdk /path/to/Android/SDK --output patched-10.18.apk
```

Поставьте полученный APK и скопируйте оригинальный OBB 10.18 в:

```text
Android/obb/com.MadOut.BIG.backend1018/main.100118.com.MadOut.BIG.backend1018.obb
```

Содержимое OBB не меняется, меняются только каталог и имя под новый package name. При первом запуске адрес, указанный патчеру, записывается в:

```text
Android/data/com.MadOut.BIG.backend1018/files/backend.txt
```

```ini
ip=192.168.1.10
port=10118
```

Этот файл можно изменить и перезапустить игру. Существующий `backend.txt` при обновлении APK сохраняется; новые параметры патчера его не перезаписывают. Нажмите **Offline or Anonim** для гостевого входа через свой сервер и перехода в одиночную игру.

Пошаговые команды Windows, ADB и диагностика: [подключение клиента](docs/CLIENT.md). Проверка исходного APK, подпись и пересборка внедряемых файлов: [документация патчера](patcher/README.md).

## Как устроен сервер

`Transport.cs` читает TCP-кадры и сериализует ответы. `Router.cs` ведёт авторизацию и маршрутизирует запросы. `Store.cs` и `SqliteDb.cs` хранят аккаунты и профиль в SQLite. `Commerce.cs` обрабатывает покупки, `Missions.cs` ведёт попытки и награды. Цены и параметры машин находятся в JSON-файлах `data/`.

Изменение баланса и профиля выполняется в одной транзакции. Ключ повтора строится из токена сессии и ID запроса. Гостевой токен хранится в базе в виде хеша, временные сессии находятся в памяти сервера. Подтверждение прохождения миссий опирается на данные клиента; это не серверная симуляция гонки.

##Дисклеймер и авторство

Этот проект является независимой фанатской разработкой и не имеет никакого отношения к MadOut Games. Весь код был создан исключительно путем реверс-инжиниринга оригинального бинарного протокола игры и не содержит в себе оригинальных ассетов, исходников или закрытых ключей.

Проект создан для сообщества модеров и реверс-инженеров, которые хотят изучать сетевую архитектуру старых игр и играть в них без привязки к нерабочим официальным серверам.

##Известные ограничения

В текущей версии некоторые цены на машины и предметы в каталоге ещё не прописаны. Из-за этого при покупке некоторых предметов может выдать ошибку. Бэкенд будет обновляться, каталог дополняться, а баги фикситься.

## Сборка и проверки

```sh
dotnet build src/AccountBackend -c Release
dotnet run --project tests/AccountBackend.Tests -c Release -- data
dotnet publish src/AccountBackend -c Release -r win-x64 --self-contained true -o dist/windows
```

Для переносимой сборки: `dotnet publish src/AccountBackend -c Release --self-contained false -o dist/portable`. На целевой машине нужны .NET 8 Runtime и SQLite 3. В Windows используется системная `winsqlite3.dll`, в Linux — `libsqlite3.so.0`. Самостоятельную Linux-сборку можно собрать с `-r linux-x64 --self-contained true`; её запуск не проверялся.
